# Security Policy

## Supported Versions

Only the latest release on the `master` branch receives security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Report them privately via
[GitHub Security Advisories](https://github.com/HrvojeZec/WebScrapingApp/security/advisories/new)
("Report a vulnerability" on the repository's Security tab).

Please include:

- a description of the issue and its impact
- steps to reproduce or a proof of concept
- affected version, branch or commit

You can expect an initial response within 7 days. Confirmed issues will be fixed in a patch
release and credited in the changelog unless you prefer to stay anonymous.

## Scope

This is a portfolio project. It reads publicly available product listings and stores no payment
data.
